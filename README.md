# 🌍 Wanderlust

Wanderlust is a full-stack web application inspired by modern travel and accommodation platforms. It allows users to explore travel listings, view property details, add reviews, and manage listings through an interactive web interface.

## 🚀 Live Demo

🔗 **[View Wanderlust Live](https://wanderlust-o5jh.onrender.com)**

## ✨ Features

* 🏡 Browse and explore travel listings
* 🔍 Search and discover available properties
* 📄 View detailed listing information
* ➕ Create new listings
* ✏️ Edit and manage listings
* 🗑️ Delete listings
* ⭐ Add and manage reviews
* 🔐 User authentication and authorization
* 👤 User login and signup
* 📱 Responsive and user-friendly interface
* ☁️ Deployed on Render
* 🗄️ MongoDB database integration

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/komal55tiwari87-eng/wanderlust.git
```

### 2. Navigate to the project directory

```bash
cd wanderlust
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create a `.env` file

Add your environment variables:

```env
ATLASDB_URL=your_mongodb_connection_string
SECRET=your_session_secret
```

### 5. Start the application

```bash
node app.js
```

For development with Nodemon:

```bash
nodemon app.js
```

### 6. Open in browser

```text
http://localhost:8080
```
